# skills

A collection of skills that teach AI agents how to handle common development tasks. Works with any agent tool that supports the [skills](https://agentskills.io/) format.

## Install

```bash
npx skills add jritsema/skills
```

## Skills

| Skill | Description |
|-------|-------------|
| **agent-sop-author** | Create and validate Agent SOPs — markdown workflows that guide AI agents through complex, multi-step tasks with RFC 2119 constraints. |
| **commit** | Make git commits using concise Conventional Commits-style messages. |
| **uv** | Use `uv` instead of pip/python/venv for running scripts, managing dependencies, and building packages. |
